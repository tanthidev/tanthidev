I enjoy turning complex ideas into practical digital products, from automation tools and license platforms to real-time game systems. My current direction is to deepen my understanding of **ERP, business workflows, and scalable internal systems**.

- Building and operating **Cypher Tool**, an automation-tool ecosystem with a website, license system, payment flow, and desktop applications.
- Developed desktop tools in Python using computer vision techniques such as OpenCV, OCR, and template matching.
- Built full-stack systems with automated payments, license activation, webhook handling, and user support workflows.
- Developed and operated **Cypher City**, a FiveM/GTA V roleplay server with custom server-side systems.

## Selected work

### Cypher Tool — Automation platform & license ecosystem

An independently operated platform for distributing and managing automation tools.

- Python desktop tools for real-time image/state recognition and configured actions.
- OpenCV, OCR, template matching, and performance-oriented processing.
- JSX and Tailwind CSS frontend; Node.js backend; MongoDB Atlas and Mongoose for data.
- Automated payment flow through PayOS webhooks, license activation, and account-based access.
- Linux VPS, Nginx, Cloudflare, DNS, SSL/TLS, and Docker-based deployment workflows.
- Serving **4,638 registered accounts** and **1,641 paid orders**.

[Visit Cypher Tool →](https://www.cyphersoft.store/)

### Cypher City — FiveM/GTA V server systems

A custom multiplayer roleplay server project where I developed the server-side systems.

- Lua scripting for FiveM/GTA V.
- Server logic, player data flows, feature integration, and operational maintenance.
- Practical experience with real-time systems, debugging, deployment, and ongoing iteration.

### Face Recognition Attendance System

A face-recognition-based attendance project.

- Computer vision workflows for detecting and recognizing faces.
- Focused on practical attendance tracking and system usability.
- Applied Python, image processing, and data handling.
